# SpeedFastPolimorfismo

Proyecto universitario en Java que implementa el concepto de **polimorfismo** en la gestión de pedidos de comida rápida.  
Incluye clases para modelar pedidos, interfaz gráfica básica y manejo de entidades.

---

## Estructura del proyecto
- **src/model/** → Clases principales (`Pedido`, `PedidoComida`, etc.)
- **src/ui/** → Interfaz gráfica y controladores
- **Main.java** → Punto de entrada del programa

---

## Conceptos aplicados
- **Polimorfismo**: Uso de métodos sobreescritos en distintas clases de pedidos.
- **Encapsulación**: Manejo de atributos privados con getters y setters.
- **Herencia**: Clases derivadas que extienden funcionalidades de la clase base `Pedido`.
